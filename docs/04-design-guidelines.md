# 승인 디자인의 구현 기준

현재 기준은 `design-baseline/`의 screen-family 시안이다. 이전 board의 큰 색 면·상단 고정 지시·48px/88px 규칙은 사용자 결정으로 폐기했다.

- 키오스크가 공간을 차지하고, 흰 안내 패널이 하단에서 겹친다. 실제 키오스크 목표와 폰 응답 버튼을 구분한다.
- 제목 1.875rem/1.48, 일반 400/목표600. 주 버튼1.625rem/최소76px(작은 높이72px). 음성·도움1.25rem.
- 초록#146C2E 지시, 파랑#0B57D0 폰 응답, 노랑#FBBC04 목표, 빨강#A50E0E 멈춤. 사용자 승인 로고 유지.
- 그림 안에 폰 제목·컨트롤을 합성하지 않는다. 이미지 생성 금지. 장면 SVG는 모의 기기의 안내용 자산이다.
- 390×844,360×640의 기본 글자와200% 글자 확대를 확인한다. 큰 글자는 세로 스크롤 허용, 작은 글자로 억지로 맞추지 않는다.
- 견본임을 명확히 하기 위해 배지를 `見本モード`로 표시한다. 원본 대비 의도된 차이다.
- 라디오 미선택 외곽만 #9BA8AF에서#78858D로 보정했다. 흰 배경 대비2.44:1→3.79:1. 위치/크기는 유지한다.
- 재촬영·오류·안전·직원 화면과 키보드 초점도 제품의 일부다. 최종 음원·실폰 검증 상태는 frontend-status에서 구분한다.
- PR #5(밝은 안내 화면): 밝은 하늘색 배경, 헤더의 「ステップ n / N」, 누를 버튼을 기기와 같은 색의 키 모양으로 표시, 주 버튼 아래 보조 버튼 2개. 높이 720px 이하에서 안내 제목은 26px이다. 이 값은 "글자를 줄여 맞추지 않는다"는 FR-003과 충돌하므로 결정이 필요하다.
- 높이 600px 이하에서는 그림 영역만 줄이고, 보조 버튼의 최소 높이는 48px을 유지한다.
