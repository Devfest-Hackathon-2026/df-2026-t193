# 사용성·완성도 보강 스펙

상태: **구현 완료, 웹 배포됨(2026-11-09). 실제 고령자 테스트 대기**
작성: 2026-11-09 JST. 근거는 배포 화면 전체를 렌더해 측정한 결과와 사용 흐름 점검이다. 실제 고령자 테스트는 아직 하지 않았다.

## 1. 요구사항

**U1 — 실제 카메라 화면의 주 버튼이 첫 화면 안에 보인다.** 주소창을 뺀 높이(375×553, 360×560, 393×659)에서 「撮る」와 「困ったとき」가 스크롤 없이 보인다. 카메라 영상 영역이 줄어드는 쪽으로 맞춘다. 글자를 줄여서 맞추지 않는다. 사진 주의 문구는 18px 이상으로 한다.

**U2 — 카메라 권한 단계에서 할 일을 알려 준다.** 권한 창을 기다리는 동안 「許可」를 누르라고 글자와 음성으로 안내한다. 카메라를 쓸 수 없을 때는 브라우저 설정 대신 다시 시도나 직원 상담을 안내한다.

**U3 — 직원 화면에서 실수로 처음으로 돌아가지 않는다.** 돌아갈 안내가 있으면 주 버튼은 「案内に戻る」, 「はじめに戻る」는 보조 버튼으로 둔다.

**U4 — 뜻이 어긋나는 문구를 고친다.** 사용법 시트의 닫기 버튼은 「閉じる」, 멈춤 화면의 주 버튼은 「入力の案内を見る」로 한다.

**U5 — 모의 접수기를 영상에 보일 수 있게 다듬는다.** 제목 중복을 없애고, 「デモ用の模擬端末」를 크게 표시하고, 버튼이 화면 끝에 붙지 않게 하고, 아래쪽 빈 공간을 기기 테두리처럼 보이게 한다.

**U6 — 멈춤 화면을 다른 시트와 구분한다.** 빨강 띠와 빨강 제목, 더 큰 아이콘을 쓴다. 색만으로 구분하지 않도록 제목 문구는 유지한다.

**U7 — 읽는 중임을 눈으로 알 수 있다.** 재생 중에 음성 아이콘을 움직인다. 움직임 줄이기 설정에서는 움직이지 않는다.

## 2. 이번에 하지 않는 것

- **진료과 1탭 선택:** 스펙 FR-009가 잘못 누름을 막으려고 선택과 확정을 분리했다. 고령자 테스트 결과를 보고 결정한다.
- **조작음 자동 진행:** 범위 밖.
- **작은 화면의 안내 단계:** 375×553에서는 키오스크 목표를 가리지 않기 위해 「困ったとき」가 스크롤 아래에 남는다.
